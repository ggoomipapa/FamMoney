1. 메인화면 변경사항
================================================================================

1.1 플러스 버튼(FAB) 제거
    - 기존: 우측 하단에 플로팅 액션 버튼(+)이 있었음
    - 변경: 해당 버튼 제거됨

1.2 자녀 수입 아이콘
    - 위치: 상단 바의 통계 버튼(막대그래프) 왼쪽
    - 아이콘: 아기 모양 (ChildCare)
    - 표시 조건: 설정에서 "자녀 수입 기능 사용"이 활성화된 경우에만 표시
    - 클릭 시: 자녀 수입 화면으로 이동

2. 수입/지출 유형 선택 기능
================================================================================

2.1 수입 세부 유형 (IncomeSubType)

    [급여 관련]
    - 월급: 매월 받는 정기 급여
    - 휴가비: 휴가 시 지급되는 수당
    - 명절상여: 설/추석 등 명절에 받는 상여금
    - 성과급: 실적에 따른 보너스
    - 야근수당: 초과 근무에 대한 수당
    - 인센티브: 목표 달성 시 지급되는 보상
    - 연말정산: 연말정산 환급금

    [기타 수입]
    - 이체받음: 계좌로 이체받은 금액
    - 이자: 예금/적금 이자 수입
    - 환불: 물품 반품 등으로 인한 환불
    - 용돈: 가족 등에게 받은 용돈
    - 축의금/조의금: 경조사 관련 수입
    - 기타: 위 항목에 해당하지 않는 수입

2.2 지출 세부 유형 (ExpenseSubType)

    [이체 관련]
    - 가족이체: 가족에게 보내는 이체
    - 지인이체: 친구/지인에게 보내는 이체
    - 저축이체: 저축 계좌로의 이체
    - 대출상환: 대출금 상환
    - 월세이체: 월세 납부
    - 보험료: 보험료 납부
    - 투자이체: 투자 계좌로의 이체
    - 기타이체: 위 항목에 해당하지 않는 이체

    [일반 지출]
    - 카드결제: 신용/체크카드 결제
    - 현금결제: 현금 지출
    - 자동이체: 정기 자동이체
    - 기타: 위 항목에 해당하지 않는 지출

3. 자녀 수입 기능
================================================================================

3.1 기능 개요
    - 목적: 자녀가 받은 용돈, 세뱃돈 등을 별도로 관리
    - 특징: 가계부와 별개로 관리되지만, 그룹 멤버와 공유됨
    - 활성화: 설정 > "자녀 수입 기능 사용" 토글로 ON/OFF

3.2 자녀 관리
    - 추가: 우측 상단 사람+ 아이콘으로 자녀 추가
    - 이름 입력: 자녀 이름 설정 가능
    - 수정: 자녀 정보 카드에서 연필 아이콘으로 수정
    - 삭제: 휴지통 아이콘으로 삭제 (모든 수입 기록도 함께 삭제됨)
    - 복수 자녀: 여러 명의 자녀 등록 가능

3.3 수입 기록
    - 금액 입력: 받은 금액 입력
    - 준 사람 선택: 누구에게 받았는지 선택
    - 메모: 추가 메모 입력 가능 (선택사항)

3.4 지출 기록 (아이의 경제관념 교육용)
    - 금액 입력: 사용한 금액 입력
    - 카테고리 선택: 무엇을 샀는지 선택
    - 사용처: 어디서 샀는지 입력 (선택사항)
    - 메모: 추가 메모 입력 가능 (선택사항)

3.5 지출 카테고리 (ExpenseCategory)

    [먹거리]
    - 간식
    - 음료
    - 식사

    [놀이/취미]
    - 장난감
    - 게임
    - 책
    - 문구

    [생활]
    - 옷
    - 악세서리

    [저축/기타]
    - 저축 (돼지저금통 등)
    - 선물
    - 기부
    - 기타

3.6 준 사람 유형 (IncomeGiverType)

    [친가]
    - 친할머니
    - 친할아버지

    [외가]
    - 외할머니
    - 외할아버지

    [친척]
    - 삼촌
    - 이모
    - 고모
    - 고모부
    - 기타 친척

    [기타]
    - 친구
    - 회사동료
    - 이웃
    - 기타 (직접 이름 입력 가능)

3.7 잔액 표시
    - 자녀별 수입/지출/잔액이 카드에 표시됨
    - 잔액 = 총 수입 - 총 지출
    - 수입/지출 추가/삭제 시 자동으로 업데이트

3.8 그룹 공유
    - 자녀 수입 기록은 가계부를 공유하는 모든 멤버가 볼 수 있음
    - 누가 기록했는지 표시됨

4. 공유 범위 설정 기능 (프라이버시 보호)
================================================================================

4.1 기능 개요
    - 목적: 혼자 사용하다가 다른 사람과 공유할 때 이전 거래 내역 보호
    - 원리: 특정 날짜 이후의 거래만 공유하거나, 특정 거래를 숨길 수 있음

4.2 공유 시작일 설정
    - 위치: 설정 > 초대 코드 복사 버튼 클릭 시
    - 동작:
      1. 초대 코드 복사 버튼 클릭
      2. 공유 범위 설정 다이얼로그 표시
      3. 공유 시작일 선택 (캘린더에서 날짜 선택)
      4. "모든 거래 공유" 또는 특정 날짜 선택
      5. 확인 클릭 시 초대 코드가 클립보드에 복사됨
    - 효과: 선택한 날짜 이전의 거래는 새로 참여하는 멤버에게 보이지 않음

4.3 특정 거래 숨기기
    - hiddenTransactionIds: 숨기고 싶은 거래의 ID 목록
    - 해당 목록에 포함된 거래는 다른 멤버에게 보이지 않음

4.4 필터링 동작 방식
    - 본인 거래: 항상 모두 표시됨
    - 다른 멤버 거래:
      * 해당 멤버의 shareFromDate 이전 거래 → 표시 안 됨
      * 해당 멤버의 hiddenTransactionIds에 포함된 거래 → 표시 안 됨
      * 위 조건에 해당하지 않는 거래 → 정상 표시

4.5 사용 시나리오 예시
    1. A가 1년간 혼자 가계부 사용
    2. A가 배우자 B를 초대하기로 결정
    3. A가 설정 > 초대 코드 복사 클릭
    4. "2024년 1월 1일" 선택 (올해부터만 공유)
    5. 초대 코드가 복사됨
    6. B가 초대 코드로 참여
    7. B는 2024년 1월 1일 이후의 A 거래만 볼 수 있음
    8. A의 2023년 이전 거래는 B에게 보이지 않음

5. 백업 및 복원 기능
================================================================================

5.1 기능 개요
    - 목적: 가계부 데이터를 파일로 백업하고, 다른 기기에서 복원
    - 위치: 설정 > 데이터 관리 > 백업 및 복원

5.2 백업 방법
    1) '백업 및 복원' 화면 진입
    2) '백업하기' 버튼 클릭
    3) 백업 데이터 준비 완료 후 '파일로 저장하기' 클릭
    4) 저장 위치 선택 (다운로드 폴더, Google 드라이브 등)
    5) 파일명: selectmoney_backup_YYYYMMDD_HHMMSS.json

5.3 백업에 포함되는 데이터
    - 모든 거래 내역 (수입/지출)
    - 자녀 정보
    - 자녀 수입 기록
    - 설정 정보 (고액 거래 기준, 선택된 은행 목록)

5.4 복원 방법
    1) '백업 및 복원' 화면 진입
    2) '복원하기' 버튼 클릭
    3) 백업 파일 선택 (selectmoney_backup_*.json)
    4) 백업 내용 확인 (거래 건수, 자녀 수 등)
    5) '복원하기' 버튼으로 복원 진행

5.5 복원 시 주의사항
    - 복원된 데이터는 현재 가계부에 "추가"됨
    - 기존 데이터는 삭제되지 않음
    - 동일한 백업을 여러 번 복원하면 중복 데이터 발생 가능

5.6 폰 초기화 전 체크리스트
    1) Google 계정 로그인 확인
       - 로그인되어 있으면 클라우드에 데이터 자동 저장
       - 새 폰에서 같은 계정으로 로그인 시 자동 동기화

    2) 백업 파일 생성
       - 만약을 위해 백업 파일 생성 권장

    3) 백업 파일 안전 보관
       - Google 드라이브에 업로드 (폰 초기화 시 폰 내부 파일 삭제됨)
       - PC로 복사
       - 카카오톡 나에게 보내기로 전송

5.7 새 폰에서 복원하는 방법
    1) 셀렉트머니 앱 설치
    2) Google 계정으로 로그인
       → 클라우드 데이터 자동 동기화
    3) 필요 시 백업 파일로 추가 복원
       → 설정 > 백업 및 복원 > 복원하기

6. 기존 기능 (변경 없음)
================================================================================

6.1 자동 거래 감지
    - 은행/카드사 알림을 자동으로 파싱
    - 18개 은행 및 카드사 지원

6.2 그룹 가계부 공유
    - 초대 코드로 가족 구성원 초대
    - 실시간 거래 동기화
    - 그룹 알림 설정

6.3 고액 거래 확인
    - 설정 금액 이상 거래 시 확인 다이얼로그 표시
    - 기본값: 100만원

6.4 통계 기능
    - 월별 수입/지출 통계
    - 카테고리별 지출 분석

6.5 은행 설정
    - 알림 파싱할 은행/카드사 선택
    - 개별 은행 ON/OFF 가능

7. 데이터 구조 변경사항
================================================================================

7.1 Transaction 모델 추가 필드
    - incomeSubType: 수입 세부 유형
    - expenseSubType: 지출 세부 유형

7.2 User 모델 추가 필드
    - shareFromDate: 공유 시작일 (이 날짜 이후 거래만 공유)
    - hiddenTransactionIds: 숨길 거래 ID 목록

7.3 Group 모델 추가 필드
    - childIncomeEnabled: 자녀 수입 기능 활성화 여부

7.4 새로운 컬렉션 (Firebase)
    - children: 자녀 정보 (totalIncome, totalExpense 포함)
    - childIncomes: 자녀 수입 기록
    - childExpenses: 자녀 지출 기록

8. 화면 구성
================================================================================

8.1 메인화면 (HomeScreen)
    - 상단 바: 가계부 이름, 자녀수입(조건부), 통계, 은행설정, 설정
    - 월 선택기: 이전/다음 월 이동
    - 요약 카드: 수입/지출/합계
    - 사용자 필터: 멤버별 거래 필터링
    - 거래 목록: 해당 월 거래 내역

8.2 설정화면 (SettingsScreen)
    - 계정 섹션: 로그인 상태, Google 로그인
    - 가계부 정보: 이름, 초대코드, 멤버 수
    - 자녀 수입: 기능 활성화 토글
    - 데이터 관리: 백업 및 복원
    - 거래 설정: 고액 거래 확인 기준
    - 알림 파싱 설정: 은행 선택, 알림 권한

8.3 자녀 용돈 관리 화면 (ChildIncomeScreen)
    - 상단 바: 뒤로가기, 자녀 추가 버튼
    - 자녀 선택 칩: 등록된 자녀 목록
    - 자녀 정보 카드: 이름, 수입/지출/잔액 표시, 수정/삭제
    - 수입/지출 탭: 수입 또는 지출 내역 전환
    - 내역 리스트: 날짜, 금액, 준 사람(수입) 또는 카테고리(지출)
    - 플로팅 버튼: 수입/지출 추가 (현재 탭에 따라 변경)

8.4 공유 범위 설정 다이얼로그 (SharingScopeDialog)
    - 안내 텍스트
    - 날짜 선택 카드
    - 확인/취소 버튼

8.5 백업 및 복원 화면 (BackupScreen)
    - 백업 섹션: 백업하기 버튼, 안내 보기
    - 복원 섹션: 복원하기 버튼, 안내 보기
    - 폰 초기화 전 안내: 체크리스트 보기
